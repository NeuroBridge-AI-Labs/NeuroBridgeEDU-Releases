# NeuroBridgeEDU releases

This repository holds the signed installers of **NeuroBridgeEDU** and the update manifest (`latest.json`) that the app reads to find a new version. It holds no source code.

- **Download:** see [Releases](../../releases). No public release exists yet; the app is in development.
- **Website:** https://www.neurobridgeedu.eu
- **Updates:** the app checks this repository's release list on `api.github.com` at most once a day, and you can turn that check off in Settings. Every update is signed, and the app verifies the signature before it installs anything.

NeuroBridgeEDU is a privacy-first study app: recording and transcription run on your own device.
